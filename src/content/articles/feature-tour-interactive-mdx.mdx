## Two's complement in one byte

A byte has eight bits. Read as an **unsigned** integer, the bits have weights $2^7$ through $2^0$, giving values from 0 to 255. In **two's complement**, the most significant bit instead has weight $-2^7$, giving values from $-128$ to $127$:

$$
x = -b_7 \cdot 2^7 + \sum_{i=0}^{6} b_i \cdot 2^i
$$

Try flipping bits. Setting only bit 7 gives 128 as an unsigned value but $-128$ as a signed one. Setting every bit gives 255 and $-1$.

## The same idea in C

Converting between the two interpretations does not change any bits; it only changes how they are read:

```c title="reinterpret.c"
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint8_t raw = 0xFF;
    int8_t as_signed = (int8_t)raw; /* implementation-defined before C23; -1 in practice */
    printf("%u %d\n", raw, as_signed);
    return 0;
}
```
